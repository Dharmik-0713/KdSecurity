# KdSecurity

Professional Security Research and Tooling Project.

## Project Structure

- `docs/`: Documentation, research notes, and methodology.
- `src/`: Core source code and scripts.
- `tools/`: Utility tools and third-party integrations.
- `reports/`: Security analysis reports and findings.
- `tests/`: Unit and integration tests for tools.

## Getting Started

1. Explore the `src/` directory for available scripts.
2. Check `docs/` for research documentation.
